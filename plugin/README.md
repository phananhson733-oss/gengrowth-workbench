# gengrowth-workbench

The DSH Desktop plugin of the GenGrowth SEO/GEO workbench.

- `skills/`, `prompts/` and `content.manifest.json` are generated by `scripts/sync-content.mjs` from the GenGrowth marketing content. Do not edit them by hand.
- `dsh/` is the server entry. It registers the bundled skills and prompt templates, the `gengrowth_*` tools and one system prompt section.
- `lib/client.js` is the client entry. It registers the workbench with DSH Desktop as a custom frame: the native conversation docked beside a status panel that can be collapsed.

The tools call the GenGrowth workbench API. The plugin reads its address and bearer token from `api.json` in the plugin data directory, `$DSH_HOME/gengrowth-workbench/api.json`:

```json
{ "baseUrl": "https://<your api host>", "token": "<api token>" }
```

See the repository `docs/` for the architecture and the verification record.
